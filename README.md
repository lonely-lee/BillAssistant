## 功能介绍
### 1. 账单介绍
- 脚本解析来自京东、支付宝、微信三种来源的初始账单(从官方下载解压的*.cvs文件)
- 读取每月初始账单，并将交易类型、收支等进行统一化，便于统计，统计后的账单，每条交易有以下数据：
 - 来源：支付宝、微信、京东
 - 交易时间：
 - 交易类型
 - 类型细化：预留后续精细化
 - 交易对方：商家名称
 - 商品：商品名称或说明
 - 交易状态：交易成功、交易失败、待定
 - 交易方式：花呗、信用卡、现金、其他
 - 收/支：收入、支出、不计收支、待定
 - 金额：
- 其中交易类型如下：
 - 交易类型：交通出行、餐饮美食、投资理财、生活开支、日用百货、文化休闲、鞋帽服饰、消费还款、其他
  - 交通出行：打车、公交、地铁、燃油、火车等
  - 餐饮美食：三餐、零食、聚餐
  - 投资理财：基金、股票，改行后续剔除，专门做一个投资表格
  - 生活开支：水电燃气费、电话费、宽带费、租房
  - 日用百货：洗漱用品、护肤精华、厨卫用品、生活电器
  - 鞋帽服饰：衣服、鞋子、行李箱、背包、袜子
  - 文化休闲：书籍、游戏、博物馆
  - 数码电子：手机电脑游戏机、相机、镜头
  - 消费还款：花呗、招商信用卡、白条
  - 其他：
  - 待用户确定
- 按照交易类型分析每月总支出、收入等

### 2.使用方法
环境安装部署后，通过python启动脚本
```bat
cd $(pwd)/src
python ./main.py [option]
```
其中option为可选参数，可选参数有：
- -h：显示帮助信息
- -d：指定数据库文件路径
- -c：指定配置文件路径
- -t：指定数据表名称
- -s：指定SQL文件路径
建议按照如下步骤使用：
1. 首先将本月的京东、支付宝、微信账单下载保存到***路径下
2. 启用脚本初步解析统一化本月各个来源的账单
   1. 初步处理解析的账单位于`_output/tmp_processed_to_review.csv`
   2. 本次解析可选添加到分类器训练集的数据保存在`_output/tmp_new_train.csv`
   3. 依据需要修改`tmp_processed_to_review.csv`中`新交易类型`一列的交易类型
   4. 依据需要修改`tmp_new_train.csv`中`新交易类型`一列的交易类型
3. 运行`python3.7 main.py`依据修订后的`tmp_processed_to_review.csv`表中数据，创建统计图以及本月总账单数据`yy_mm_total_bill.xlsx`，其中的`total`包含本月所有交易，`ansyls`包含本月各个交易类型分析，`月度汇总`包含本月的总支出、总收入等
4. 依据需要可选是否将修改后的`tmp_new_train.csv`数据添加到分类器训练集：`python3.7 main.py`
